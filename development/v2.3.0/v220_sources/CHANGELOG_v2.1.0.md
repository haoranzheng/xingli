# 星黎 MO2 小助手 v2.1.0

## 整合包安全一键修复

- 健康检查从只读检测升级为“检查 + 可回滚安全修复”。
- 自动修复范围：MOD 启停状态、在 MOD 集合完全一致时的左侧顺序、以及基准中保存了精确快照的 plugins/loadorder/Profile INI。
- 缺失 MOD、新增 MOD、删除文件、下载安装 MOD、存档和复杂冲突始终只报告，不自动处理。
- 自动修复执行前展示预览；执行过程保存 pending 快照，失败自动回滚并立即校验。
- 若修复过程中 MO2/插件异常退出，下次打开“整合包检查”可恢复到修复开始前状态。
- v2.1 基准升级为 schema 2：保存 MOD 数字优先级与配置文件精确字节快照。旧基准仍可检查，但要启用顺序/文件修复需更新一次基准。
- 保持 MO2 2.4.4 兼容约束：不引入 pluginList/onModStateChanged/waitForApplication 等已知危险接口。
