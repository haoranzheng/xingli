# 星黎 MO2 小助手 v1.9.1

## UI 精简与易读性整理

- 不改变 v1.9.0 的 MOD 组、状态事务、回滚和 LOD 功能逻辑。
- 删除主界面和功能页中对普通用户无帮助的内部实现说明。
- 模组管理中心不再显示 IOrganizer、Essential、状态事务等开发术语。
- LOD 页面不再直接展示 GrassPrecacher、PrecacheGrass.txt、缓存扩展名等内部细节。
- 简化 LOD 主界面、生成设置、草缓存提示和错误提示。
- 高级功能按钮移除重复的“（高级）”后缀；新手模式仍会隐藏这些功能。
- 压缩工具、用户助手、DSD 和游戏路径提示改为更直接的操作说明。
- 所有不可逆或高风险操作的必要确认仍然保留。
