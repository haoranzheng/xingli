# v2.1.1 — Onboarding + Update UX + Main Menu Sync

- 新增桌面【星黎帮助与教程.bat】：无需知道 MO2 插件入口，打开后自动显示教程中心；MO2 已运行时也可触发。
- 首次欢迎页改为一次性新手引导，不再每次启动 MO2 都弹出。
- 教程中心改为“内置当前版教程 + 外部参考”，覆盖启动、小助手入口、两类更新、健康修复、ENB、LOD/Grass 与安全事务。
- 主页明确拆分【助手更新】与【整合包更新】，分别提供明确按钮；新增【检查全部更新】避免含糊的“更新/检查”入口。
- 用户助手中的更新入口同样拆分为【助手更新】与【整合包更新】。
- 新增 Main Menu Customizer 同步：自动把游戏主菜单的安装版本同步到当前整合包版本，并把公开更新状态/说明写入其版本列表文本。
- Main Menu Customizer 只修改 [Version] 的 sText 与 versionlist 指定的数据源文件，不改其它按钮、布局、赞助者或 debug 设置。
- 修正 MO2 插件 VersionInfo 与实际版本不一致的问题。
