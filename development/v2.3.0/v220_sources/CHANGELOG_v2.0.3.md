# 星黎 MO2 小助手 v2.0.3

- 正式启用星黎整合包 3.3.1 内容版本记录。
- 整合包更新提示支持多个网盘入口与独立提取码；当前支持夸克、百度网盘。
- 打开网盘时自动复制对应提取码到剪贴板。
- 整合包本机版本首次迁移后持久保存到 MO2 pluginDataPath，后续助手自更新不会修改内容版本。
- 后续整合包更新可在 MO2 根目录放置 `xingli_modpack_release.json` 覆盖持久版本。
- 修复 Grass 断点继续时原始 MOD 状态被重新应用策略清空的问题。
- 新增流水线级 MOD 状态基线：成功或最终失败后恢复所有运行前已存在 MOD 的启停状态。
- 生成过程中需要给下游使用的 Output MOD 可临时启用；流水线结束后，原本关闭的 Output MOD 会恢复关闭。
- 新生成且运行前不存在的 Output MOD 保持启用。
- 外部 LOD 工具运行时阻止直接关闭 LOD 窗口，避免丢失完成回调和 MOD 状态恢复。
- “检查变化 / 打开设置 / 不执行生成”路径保持只读，不会启用或禁用任何 MOD。
