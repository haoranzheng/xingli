# 整合包检查与安全修复

## 1. 建立基准
在确认当前 Profile 正常后建立基准。v2.1 基准记录：
- MOD 名称、启停状态、左侧优先级；
- plugins.txt / loadorder.txt；
- Skyrim.ini / SkyrimPrefs.ini / SkyrimCustom.ini；
- 配置文件精确字节快照（仅保存在本机 pluginDataPath）。

## 2. 检查
检查只读，不会修改 MOD。报告会区分“可安全自动修复”和“需要人工处理”。

## 3. 自动修复范围
可自动修复：
- 已存在 MOD 的启停状态；
- MOD 集合没有新增/缺失时的左侧顺序；
- 基准包含精确快照的 Profile 配置文件。

不会自动处理：
- 缺失 MOD；
- 新增 MOD；
- 自动下载、安装、卸载 MOD；
- 玩家存档；
- 复杂冲突；
- 基准中不存在的文件删除。

## 4. 事务与回滚
修复流程：预览 → 保存修复前快照 → 应用 → 刷新 MO2 → 严格校验。
任一步失败都会尝试完整回滚。若程序在修复过程中异常退出，下一次进入整合包检查时会检测 pending 修复并提供恢复。
