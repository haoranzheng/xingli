# 星黎 MO2 小助手：隐私与网络说明

- 插件不包含遥测、广告 SDK、统计 SDK，也不会自动上传日志、MOD 列表、路径或诊断数据。
- 自动联网仅用于读取星黎助手更新清单/更新包，以及整合包版本清单；生产环境只允许 HTTPS。
- 助手更新仅允许来自预设 GitHub/Gitee/GitCode 域名；整合包跳转仅允许当前批准的网盘域名。
- SHA256 用于验证下载完整性。它不能替代独立的发布签名；未来版本将进一步加入签名验证。
- 教程和社区链接仅在用户主动点击时由系统浏览器打开。
- 不在发行包中保存作者电脑绝对路径、Windows 用户名、邮箱、访问令牌或 API 密钥。
- 日志默认仅保存在本机。用户公开分享日志前仍应检查其中是否包含自己的本机路径。
